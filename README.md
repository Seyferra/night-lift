# Night Lift

iPhone web app inspired by classic 1983 elevator-spy arcade games.

Not affiliated with Taito. Original title, art, and code.

## Play on iPhone

1. Open the live URL in Safari
2. Share → Add to Home Screen
3. Launch Night Lift like an app

## Controls

- D-pad: walk, duck, call / ride lifts, use stairs
- FIRE: shoot (3 shots on screen)
- JUMP: jump or jump-kick
- Stand in front of a red door and press UP to grab the file
- Collect every file, ride a lift to the garage, escape

Desktop: arrows + Z fire + X/Space jump
